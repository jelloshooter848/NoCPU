## 0.1.0 — In development

- Restart NoCPU with a desktop-first direction: all 21 DICE 0.9 games running accurately in desktop browsers is the 1.0 goal. Mobile/touch UI, phone device qualification and iPhone Home Screen support are deferred to a post-accuracy phase.
- Rewrite the agent rules and [roadmap](docs/ROADMAP.md) for the new plan and reset the project version to 0.1.0.
- Move legacy per-version task, validation and device-qualification ledgers and the legacy changelog under [docs/legacy/](docs/legacy/).
- Carry over the core, which compiles six original circuits (Pong, Pong Doubles, Space Race, Breakout, Stunt Cycle and Indy 4), and the original/native/Wasm comparison harness unchanged. No 0.1.0 build has been published.
