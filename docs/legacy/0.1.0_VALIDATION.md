# 0.1.0 qualification report

This report records the review gauntlet for the native/reference foundation. It does not describe a browser release or complete validation of all games.

## Reviewed foundation

- All 566 imported files match the original upload and the path/size/SHA-256 manifest. Root GPL text remains byte-identical.
- Historical library provenance and restored exception notices support the documented GPL version 3 source package. Native binaries, Wasm, ROMs and toolchain containers require separate distribution audits.
- The 21-game source inventory passes. All ten private ZIP fixtures pass required CRC and observed-size checks without extraction or copying into this repository.
- The documented native build completed twice from clean source copies using the fresh toolchain image. The two local binaries have SHA-256 `035cd694bb00965c703a5e4654972c011969e79f7f8acbe6a19e591d30841a0a`. This observation is not a guarantee of identical builds with future transitive apt packages.
- Package tests cover source mutation, missing/extra files, symlinks, path traversal, private payloads, deterministic archives, version/notes matching and required license notices. Both the checker and packager independently reject nested `.git` directories and worktree pointer files; the checkout's root Git metadata remains accepted and excluded.
- A scratch checkout with Git `core.autocrlf=true` preserved all imported source and pinned license bytes.

## Functional reference and gauntlet

`./tools/capture-pong.sh` passed four 16-second epochs: two seeded fresh processes, each with a circuit recreation. Every epoch asserts settled attract mode, coin/start, independently observed paddle movement, two separate contacts with rendered horizontal ball reversals, score increases, coin restart/score clearing, nonconstant native PCM and bounded input timing.

The reference observes 960 frames and 768,002 mono signed 16-bit samples at 48 kHz per epoch. Contacts occur at approximately 3.221 and 5.315 seconds, each spanning four raster HIT pulses. Maximum combined score is 2. Active PCM has 284 transitions. Corresponding fresh-process epochs have identical frame, raster, telemetry, input, collision and PCM hashes. See [PONG_REFERENCE.md](../PONG_REFERENCE.md) for assertions and [the replay](../../tests/replays/pong.tsv) for inputs.

Negative reference checks remove collision traces or replace observed frames with static paddles while keeping input logs intact. Both are rejected. Independent review also reproduced incomplete native video/PCM and missing declared replay inputs that the original analyzer accepted. Qualification now requires full-duration native media with bounded frame cadence/sample counts and an exact ordered match to the declared input replay, including tied timestamps.

The public test command passes **39 artifact-free tests**: thirteen release/preservation tests, twelve game/ROM tests and fourteen reference-analyzer helper tests. The reference suite explicitly skips its seven real-artifact cases when no capture is supplied. Running it with the genuine local capture passes all twenty-one analyzer cases: the fourteen helpers, one unmodified-capture case and six deliberately altered capture cases. These alterations include truncated video/PCM and incomplete, changed, duplicated or reordered input evidence. Independent reviewers also re-analyzed all four original local epochs and all four archived GitHub CI epochs successfully under the strengthened checks.

Reviewed commands:

```sh
make test
./tools/build-native.sh
./tools/capture-pong.sh
python3 tests/test-reference-analysis.py --reference-dir build/reference
python3 tools/audit-roms.py --rom-dir /path/to/private-fixtures
make source-candidate
make source
```

The actual ten-fixture check used an external private checkout; its payloads are excluded from the repository. `make source` packages a local source artifact and does not push a tag or publish it. Archive contents and per-file integrity are independently inspected after packaging. Workflow syntax passes actionlint, and local documentation links resolve.

## Recorded baseline differences

Fresh versus recreated epochs have different startup frame streams and initial signal values, while their settled behavior and PCM match. Do not infer complete reset isolation from this result. The first fresh native frame also produces inherited OpenGL error 1281 with initially zero projection bounds; this is recorded separately from adapter read errors. Neither observation changes the original source or suppresses a port regression.

0.1.0 is qualified as a source/native foundation candidate. The source foundation is on `main`; explicitly pushing a reviewed release tag remains a separate publication step. No release tag, GitHub release or Pages deployment has been created.

## Scope limits

Only source distribution is qualified by the license audit. Ten compatible ROM sets are private test fixtures; distribution permissions are not established. Public CI never receives their credentials or payloads.

Eight original games have no active mono audio output hookups. These inherited gaps are recorded in the compatibility matrix; reconstruction belongs to later accuracy work. Captured generated PCM and physical speaker playback are separate checks.

Browser/mobile play, phone performance, full gameplay for all 21 games, every DIP option and historical cabinet accuracy remain outside the verified 0.1.0 results.

No release tag, GitHub release, browser deployment or repository settings change has been performed by preparing this report.
