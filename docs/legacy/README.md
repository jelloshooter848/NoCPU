# Legacy line records (0.1.0–0.6.0)

NoCPU restarted with a desktop-first plan and reset its version to 0.1.0. The
files in this directory belong to the legacy line, whose final release state is
preserved at tag `legacy-0.6.0`. They are historical evidence: their task
contracts, validation ledgers and device-qualification packets do not govern
the restarted line, and their version numbers do not refer to restarted
releases. See the current [roadmap](../ROADMAP.md).
