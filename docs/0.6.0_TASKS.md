  Preserve and disclose that inherited limit. Silence comparison is distinct

## Frozen initial core contract

The selected interface is ABI 4 with per-descriptor staged buffers and core
size/CRC verification. Stunt Cycle packs misses in bits 0–2, free-game score
index `(score − 12)` in bits 3–6, coinage index in bit 7 and disabled-free-game
in bit 8; `pot=0`, default packed value 76. Free-game scores are 12–27.
Indy 4 uses `dip=0` and timer resistance 220000–1220000, default 720000.
The source-derived input/telemetry and finite canonical scenario manifests
must be agreed by engine, frontend and validation owners before acceptance.

| Selected circuit | Original controls and slots | Required browser adaptation |
| --- | --- | --- |
| Stunt Cycle | One shared throttle; Coin; separate Start 1 and Start 2 | Preserve two-player starts with one control slot, positive analog throttle or original gradual held-key rise/release decline; usable off-court touch control |
| Indy 4 | Four independent wheels and four held Gas/Hand Brake pairs; Green, Cyan, Violet, Red and Dollar coin switches; no Start | Preserve every color slot and coin channel, original relative quadrature conversion/polling, keyboard/gamepad/touch assignment and neutral release on interruption |

Controls, menu labels and settings exposure alone are not measured gameplay.
Canonical scenarios must identify the original input/configuration and actual
observations; a credit-only attract screen cannot replace played coverage.
