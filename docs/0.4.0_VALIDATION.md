# 0.4.0 first-game-batch validation

The accepted [0.4.0 contract](0.4.0_TASKS.md) adds original-derived Pong Doubles
and Space Race while preserving Pong. The intended preview has three playable
circuits and eighteen explicitly unported library entries. All three playable
titles are ROM-free; imported ROM compatibility does not unlock an unported
circuit.

The actual original/native/Wasm six-scenario fidelity and current ABI gates now
pass independent review. The user-authorized proportionate local browser scopes
also pass independent actual review, with the interrupted 220-case attempt and
all failed repair stages retained separately. Corrected PR CI and its actual
complete source/media/component/browser artifacts pass independent review.

prerequisite and skips deployment. Its measured test-only timing repair passes
independent source and affected five-profile review; follow-up committed and
exact-main acceptance remain required. No 0.4.0 public
deployment or physical-device pass is claimed.
